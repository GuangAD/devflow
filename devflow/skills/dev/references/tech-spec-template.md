# 技术规格模板

特性级整体规划文档，`spec.md`。读者是评审者和后来接手的人——**让一个没参与设计的人不用读九个任务契约就能看懂整体**。

**不设篇幅上限。** 判断标准是内容归属，不是长度——任务级细节（签名、步骤、用例）不属于这里，出现就是写错了地方。

## 骨架

```markdown
# <特性名> · 技术规格

## 整体实现

## 流程图(按需)

## 数据结构

## 模块划分

## 技术选型与约束

## 覆盖标准

## 接口面清单
```

## 逐节要求

### 整体实现

一段叙述：数据从哪进、经哪几个模块、从哪出，回答「这个特性整体怎么跑起来」。这是全文的入口，先于一切细节。

### 流程图(按需)

mermaid，承载模块间依赖方向与数据流向。**只在有真实的跨模块流向时画**；单模块或直白流程不画，不画装饰图。图不复述「整体实现」已说清的内容，两者互补。

### 数据结构

新增或修改的数据结构定义，**真实语法**，照着能写出来。类型、字段、约束、关系。

关联：这一节写「形状」，`brief` 第 2 节写「业务语义」。前者是表加什么字段，后者是文章有哪几种状态。

### 模块划分

几个模块、各自职责、谁依赖谁，**模块路径必写**。`brief` 第 3 节可能已有一段文字级模块列表，这里是它的落地版，允许细化。

按职责分，不按技术层次分。会一起改的东西住在一起。

### 技术选型与约束

用了什么、为什么用、不能碰什么。与 `brief` 第 4 节的关系：那一节是项目级约束（逐字抄来的），这一节是本特性的落地选择。

### 覆盖标准

**这份文档里最承重的一节。** 它回答「测到什么程度算全」。

先定档位：

| 档位 | 什么时候用 | 要求 |
|---|---|---|
| **完整档** | 涉及数字格式化、编码转换、多字段交互、状态机 | 等价类矩阵 + 维度两两交叉自检 + 机检铁律 + 枚举范围 |
| **抽样档** | 单向输入输出、无组合边界、错误代价低 | 五条最可能咬到用户的输入类或失败模式；另补齐未被这五条覆盖的所有高风险输入 |

默认抽样档。**判据必须写在文档里，不能靠感觉。**

两种档位的写法：

```markdown
档位:完整档

理由:中文分词的结果受「段形态 × 组位」两个维度共同影响,组合边界是主要风险。

| 维度 / 组合 | 代表输入 | 期望要点 | 落在哪 |
|---|---|---|---|
| 标题命中 × 中文 | 中文标题含关键词 | 能搜到,排第一 | T3 用例 1 |
| 正文命中 × 中文 | 正文含关键词、标题不含 | 能搜到但排在标题命中之后 | T3 用例 3 |
| 零结果 × 中文 | 不存在的词 | 返回空数组 | T6 用例 1 |
```

```markdown
档位:抽样档

理由:输入是单向字符串,没有维度组合,错误代价是显示错而不是算错。

最可能咬到的五种情况:
1. 空字符串 → 应返回空结果而不是报错 → 钉在 T3 用例 4
2. 超长输入(>10KB) → 应正常处理不崩 → 钉在 T3 用例 5
...
```

**最后那一列是硬要求：每一行必须能指到某个任务的具体用例。** 没有它，覆盖标准就是一份「我们说要测这些」的愿望清单。


**显式扫隐含高风险输入**：从目标行为、状态变化、边界与失败形态推导规格未逐字列出的危险输入；每项必须进入覆盖矩阵或抽样行，并指向任务中的具体用例。风险备注若没有对应测试，不算覆盖。
### 接口面清单

全部对外导出一行一个，标接缝 / 非接缝。

```markdown
- `search.buildIndex` -- 接缝 -- 构建时生成索引
- `search.rank` -- 接缝 -- 给结果打分排序
- `search.weights` -- 非接缝 -- 排序权重常量,只读
- `search.IdxBuilder` -- 非接缝 -- 索引构建器(有状态)
        重用语义:add 会累积,build 可重复调用返回同一结果
```

规矩：

- **只写名字和一句话，不写签名。** 签名在任务契约里，这里写了就是重复
- **非接缝的有状态导出必须写一行重用语义。** 教训：builder 复用未清空缓冲区，几何翻倍，复审才抓到
- 实现期新增的导出必须回填这张表，不允许「整层只靠一句模式约定」

## 硬规矩

- 整体实现必写，放在全文开头；流程图按需
- 接口面清单不写签名
- 覆盖标准必须写档位与理由
- 覆盖标准的每一行都要有「落在哪」一列
- 数据结构只写这一层该写的形状，不写具体函数的内部结构
- 模块划分必写模块路径；文件级落点归任务契约，不在本节铺开
